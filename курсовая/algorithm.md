# Алгоритм для курсовой работы
## 1. Основные понятия для дальнейшего описания
- **Линия** - пять клеток подряд в одном из четырёх направлений: горизонталь, вертикаль, диагонали
- **Окно** - конкретный набор из 5 клеток подряд в одном направлении: для клетки (r, c) всего до 5 окон (меньше у краёв поля)
- **Открытая четвёрка** - четыре знака одного игрока подряд, и оба конца этой линии свободны (_ О О О О _) Если у игрока есть открытая четвёрка, он выигрывает на следующем ходу, потому что может поставить знак в любой свободный конец, а противник не может заблокировать оба конца за один ход
-  **Четвёрка с дыркой** - Четыре знака одного игрока, одна пустая клетка внутри граничных знаков (О О _ О О)
- **Полуоткрытая четвёрка** - Четыре знака подряд, но только один конец свободен (О О О О _) Такую четвёрку можно заблокировать, заняв единственный свободный конец
- **Открытая тройка** - Три знака одного игрока подряд, оба конца свободны ( _ О О О _ )
- **Полуоткрытая тройка** - Три знака одного игрока подряд, один из концов свободен ( О О О _ )
- **Вилка** - Ход, который создаёт две или более угрозы одновременно (две открытые тройки, или открытую тройку + открытую четвёрку). Противник может заблокировать только одну угрозу.
- **Изолированная клетка** - клетка, у которой все существующие соседи (8 направлений) — это препятствия (#) или знаки противника.Такие клетки исключаются из рассмотрения полностью

## 2. Приоритет угроз
На этом этапе бот просматривает **все неизолированные пустые клетки**. Для каждой клетки проверяются все 4 направления. Клетка получает тип угрозы по таблице ниже.
| № | Тип угрозы | Очки | Действие |
|---|------------|------|----------|
| 1 | Моя открытая четвёрка | +1000 | Немедленный ход |
| 2 | Моя полуоткрытая четвёрка	| +800 | Немедленный ход |
| 3 | Моя четвёрка с дыркой	| +600 | Немедленный ход |
| 4 | Открытая четвёрка противника	 | -800 | Немедленная защита |
| 5 | Полуоткрытая четвёрка противника	 | -600 | Немедленная защита |
| 6 | Четвёрка противника с дыркой	| 	-400 | Немедленная защита |
| 7 | Моя вилка (2+ угрозы)	| +200 | В список на анализ |
| 8 | Вилка противника	| -150 | В список на анализ |
| 9 | Моя открытая тройка | +50 | В список на анализ |
| 10 | Открытая тройка противника | -40 | В список на анализ |

**Если клетка подходит под несколько типов, выбирается наивысший приоритет (меньший номер)**

**Примечание:** Полуоткрытые тройки (например, О О О _ _) в таблицу не включены, так как они не создают немедленной угрозы и будут учтены в эвристике (3 знака = 20 очков) или обнаружены поиском на 2 хода

## 3. Немедленные действия

### 3.1. Особое правило для последнего хода (только для ноликов)

**Когда применяется:**
- Бот играет за нолики (O)
- Первый игрок (X) уже собрал линию из 5 в ряд
- Игра ещё не закончена (по правилам: X выигрывает, только если O не может ответить)

**Действие бота:**
Бот ищет **только клетки, где он сам может собрать 5 в ряд** (типы 1–3 из таблицы — открытая четвёрка, полуоткрытая четвёрка, четвёрка с дыркой).

| Типы | Действие |
|------|----------|
| 1–3 (моя победа) | Сходить туда (если несколько — любую), будет **ничья** |
| Нет таких клеток | Сходить в любую пустую клетку, будет **проигрыш** |

### 3.2. Обычные немедленные действия (для всех игроков)

Если на этапе 2 найдены клетки типов **1–6**, бот действует по следующему приоритету:

#### Для второго игрока (O) — стандартное правило

| Тип | Действие |
|-----|----------|
| 1–3 (моя победа) | Выбрать эту клетку, **победа** |
| 4–6 (победа противника) | Выбрать эту клетку для блокировки |

#### Для первого игрока (X) — с исключением

**Применяем блокировку вместо победы, только если:**
- Моя четвёрка — **открытая (тип 1)**
- И четвёрка противника — **полуоткрытая (тип 5) или с дыркой (тип 6)**

В этом случае блокировка даёт **гарантированную победу** на следующем ходу

### 3.3. Общие правила для обоих игроков

Если найдено **несколько клеток типа 4–6** (противник может выиграть разными ходами), выбирается клетка с **наивысшей эвристической оценкой** (пункт 6).

**Если ни одно из правил пункта 3 не применилось** — переходим к пункту 4.

## 4. Явная проверка вилок (перед поиском)

### Проверка своих вилок
Поиск на 2 хода может не заметить вилки, которые создаются **сразу** нашим ходом (без ответа противника). Поэтому перед поиском выполняется отдельная проверка.

Для каждой клетки из типов 7–10, кроме вилок противника, которые являются кандидатами:
- Временно поставить свой знак в эту клетку
- Подсчитать количество угроз:
    + открытых четвёрок (тип 1)
    + полуоткрытых четвёрок (тип 2)
    + четвёрок с дыркой (тип 3)
    + открытых троек (тип 9)
- Если угроз >= 2:
    + Это вилка
    + Добавить клетку в список вилок

Если список вилок не пуст:
- Выбрать клетку с **наивысшей эвристической оценкой**
- Ходить туда **немедленно**

### Проверка вилок противника
Если свои вилки не найдены, проверяем, может ли противник создать вилку.
Для каждой неизолированной пустой клетки:
- Временно поставить знак противника в эту клетку
- Подсчитать количество угроз:
    + открытых четвёрок (тип 4)
    + полуоткрытых четвёрок (тип 5)
    + четвёрок с дыркой (тип 6)
    + открытых троек (тип 10)
- Если угроз >= 2:
    + Это вилка противника
    + Добавить клетку в список вилок противника

Если список «вилки противника» не пуст:
- Выбрать клетку с **наивысшей эвристической оценкой** 
- Ходить туда **немедленно** (блокируем вилку противника)

## 5. Поиск на 2 хода вперёд
### Когда включаем: 100-300 пустых клеток, тк
- больше 300 — начало игры, мало угроз
- меньше 100 — конец игры, эвристика быстрее и точнее
- 100–300 — самая важная фаза, нужен поиск

### Контроль времени
Перед поиском запоминаем время начала. После каждого проверенного кандидата смотрим, прошло ли больше 90 мс

Что делаем, если прошло больше 90 мс:
- Немедленно прекращаем проверку дальнейших кандидатов
- Берём лучшего из уже проверенных кандидатов
- Если кандидатов не было, переходим к эвристике (пункт 6)

### Кандидаты для поиска
Кандидатами являются **все клетки, которые в пункте 2 получили типы 7–10, кроме вилок противника,** (вилки и открытые тройки).

### Как оценивается один ход (для одной клетки-кандидата А)
1. Мысленно поставить свой знак в клетку A
2. Найти лучший ответ противника — выполнить пункт 2 (таблица угроз) для знака противника. Противник выберет ход с наименьшей оценкой (самый неприятный для нас)
3. Мысленно поставить знак противника в найденную клетку
4. Снова выполнить пункт 2 для себя — оценить, какая позиция получилась после ответа противника
5. Посчитать итоговые очки по таблице

| Ситуация (после ответа противника) | Очки |
|------------------------------------|------|
| У меня 5 в ряд (победа) | +1000 |
| У противника 5 в ряд (проигрыш) | -800 |
| У меня открытая четвёрка | +150 |
| У меня полуоткрытая четвёрка | +120 |
| У меня четвёрка с дыркой | +100 |
| У противника открытая/полуоткрытая четвёрка или четвёрка с дыркой | -80 |
| У меня открытая тройка | +50 |
| У противника открытая тройка | -40 |

6. Сумма очков — это оценка хода A

###  Выбор хода
- Из всех рассмотренных кандидатов выбирается клетка с **наибольшей суммой очков**
- Если сумма очков **> 0**, то ход принимается, бот ходит туда
- Если сумма очков **<= 0** (или поиск не дал результатов), то бот переходит к эвристике (пункт 6)

## 6. Обычная эвристическая оценка
Используется, когда:
- На этапе 2 не найдено ни одной опасной клетки
- Или поиск на 2 хода не дал положительного результата
- Или поиск не включался

Рассматриваются **только не изолированные** пустые клетки. Изолированные клетки **полностью исключаются**

### Оценка одной клетки
Для каждой клетки (r, c) считается:

### Шаг А. Атака (мои знаки в окнах)
Для каждого из 4 направлений и каждого окна из 5 клеток, содержащего (r, c):
- Если в окне **нет** знаков противника и препятствий:
    | Своих знаков в окне | Очки |
    |---------------------|------|
    | 1 | +1 |
    | 2 | +4 |
    | 3 | +20 |
    | 4 | +200 |
    | 5 | +1000 |

### Шаг Б. Защита (знаки противника в окнах)
Для каждого из 4 направлений и каждого окна из 5 клеток, содержащего (r, c):
- Если в окне **нет** моих знаков и препятствий:
    | Чужих знаков в окне | Очки |
    |---------------------|------|
    | 1 | +0.9 |
    | 2 | +3.6 |
    | 3 | +18 |
    | 4 | +180 |
    | 5 | +900 |

### Шаг В. Бонус за близость к 4 центрам четвертей
Мы хотим поощрить клетки, которые находятся близко к любому из четырёх центров четвертей:
- (5,5) — левая верхняя четверть
- (5,14) — правая верхняя четверть
- (14,5) — левая нижняя четверть
- (14,14) — правая нижняя четверть

Чем ближе клетка к любому из этих центров, тем больше бонус

Между двумя клетками на поле можно двигаться по горизонтали, вертикали и диагонали. Поэтому мы используем **расстояние Чебышёва**:
```bash
расстояние чебышёва до одного центра = max(|r - cr|, |c - cc|)
```

```bash
минимальное расстояние = наименьшее_из_всех_4_расстояний
```

Если расстояние > 10, формула даст отрицательное число, поэтому сравниваем с 0
```bash
бонус_за_центры = max(0, 20 - минимальное_расстояние × k)
```
где k — коэффициент, выбранный равным **2** (чтобы бонус был заметным, но не перебивал атаку и защиту)

### Шаг Г. Бонус за близость к своим знакам
Чем ближе пустая клетка к уже существующим знакам бота, тем больше очков она получает

Между двумя клетками на поле можно двигаться по горизонтали, вертикали и диагонали. Поэтому мы используем **расстояние Чебышёва**:
```bash
расстояние чебышёва до своего знака = max(|r - r2|, |c - c2|)
```

Максимальное расстояние между двумя клетками в одной линии длины 5 равно **4** (от первого знака до пятого)

Для каждого своего знака на расстоянии d (от 1 до 4) от оцениваемой клетки:
```bash
бонус от 1 знака = (5 - d) * k
```

где k — коэффициент, выбранный равным **2** (чтобы бонус был заметным, но не перебивал атаку и защиту)

| Расстояние d | 5 - d | * | Бонус от одного знака|
|--------------|-------|---|-------|
| 1 | 4 | ×2 | 8 |
| 2 | 3 | ×2 | 6 |
| 3 | 2 | ×2 | 4 |
| 4 | 1 | ×2 | 2 |
| 5 и больше | — | — | 0 |

Бонусы от **всех** своих знаков на расстоянии <= 4 **складываются**

### Шаг Д. Итоговая оценка
```bash
оценка клетки = атака + защита + бонус за центры + бонус к своим
```
### Выбор хода
- Выбирается клетка с **максимальной** оценкой
- Если несколько клеток набирают одинаковое максимальное количество очков, выбирается **случайная** из них
